# Contributing

The code is open, but **pull requests are not accepted for now**: keeping all changes in one pair of hands keeps the
project consistent while it is still taking shape.

What is very welcome:

- **Suggestions and ideas** for the app.
- **Questions** about using it or about how it works: they will be answered as soon as possible.
- **Bug reports**, with what you did, what you expected and what happened (screenshots help).

Please use the repository's **[Discussions](../../discussions)** tab for all of these, if possible. Portuguese and
English are both fine.

# Contribuindo

O código é aberto, mas **por enquanto não aceito pull requests**, para manter o controle das coisas enquanto o projeto
ainda está tomando forma.

Toda sugestão é bem-vinda, e dúvidas serão respondidas o mais rápido possível. Se puder, use a aba
**[Discussions](../../discussions)** do repositório (português ou inglês).
